## 📊 **Visualização de Dados - Storytelling com Dados**

### **Gráficos Interativos com D3.js**
```javascript
// Gráfico de barras interativo
const data = [12, 19, 3, 5, 2, 3];
const svg = d3.select('#chart')
    .append('svg')
    .attr('width', 400)
    .attr('height', 300);

svg.selectAll('rect')
    .data(data)
    .enter()
    .append('rect')
    .attr('x', (d, i) => i * 50)
    .attr('y', d => 300 - d * 10)
    .attr('width', 40)
    .attr('height', d => d * 10)
    .attr('fill', 'steelblue');
```
