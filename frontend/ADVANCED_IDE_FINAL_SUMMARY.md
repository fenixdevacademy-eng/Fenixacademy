## 🚀 Como Usar

### Gerenciador de Extensões
1. Clique no ícone de **Package** na barra de ferramentas
2. Navegue pelas categorias ou use a busca
3. Clique em **Instalar** para adicionar extensões
4. Use **Ativar/Desativar** para controlar extensões instaladas
5. Clique no ícone de **Info** para ver detalhes completos

### Assistente de IA
1. Clique no ícone de **Brain** na barra de ferramentas
2. Digite sua pergunta ou comando no campo de entrada
3. A IA analisará seu código e fornecerá sugestões
4. Use as sugestões clicando em **Aplicar**
5. Configure o comportamento nas configurações
