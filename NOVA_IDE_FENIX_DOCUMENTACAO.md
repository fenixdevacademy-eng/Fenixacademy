# 🚀 Nova Fênix IDE - Documentação Completa

## 🎯 Visão Geral

A **Nova Fênix IDE** é uma IDE completamente redesenhada e inovadora, construída com as melhores tecnologias web e mantendo a paleta de cores característica da Fênix Academy. Esta IDE oferece uma experiência de desenvolvimento moderna, intuitiva e poderosa.

### 🎨 **Design Inovador**

## 🚀 **Como Usar**

### **1. Acessar a IDE**
```
URL: /ide-advanced
```

### **2. Criar um Projeto**
1. Clique em "Novo Arquivo" na barra de abas
2. Escolha a linguagem desejada
3. Comece a codificar

### **3. Executar Código**
1. Abra o terminal (Ctrl+`)
2. Digite o comando de execução
3. Veja o resultado no terminal

### **4. Preview em Tempo Real**
1. Crie um arquivo HTML
2. O preview será atualizado automaticamente
3. Use os modos de visualização (Desktop/Tablet/Mobile)

### **5. Usar a Paleta de Comandos**
1. Pressione Ctrl+Shift+P
2. Digite o comando desejado
3. Pressione Enter para executar
